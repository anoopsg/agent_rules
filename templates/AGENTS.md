## Behavior Contract

Every agent turn that produces or modifies code MUST end with the
disclosure lines defined by these always-on rules:

| Concern | Always-on rule | Skill | Disclosure line in turn summary |
| :--- | :--- | :--- | :--- |
| No fabricated APIs | `core/verification` | `prevent-hallucination` | implicit via citations (`file:line`) |
| Code is testable + tests ship | `core/testability` | `testable-code` | `tests: <N> green, <M> added` |
| UI doesn't visually regress | `flutter/golden_testing` | `golden-sandbox` | `goldens: <N> green` |

Silent skip is a rule violation. The skill files document the exact
disclosure formats and skip-eligibility criteria.
