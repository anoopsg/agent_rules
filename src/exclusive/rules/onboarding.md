# Onboarding (Launchpad)
- Before structural or architectural changes, read root `AGENTS.md` (naming, routing) and `contracts/` (`contracts/README.md` indexes them; `contracts/openapi.json` is the source of truth for the backend).
- If `docs/` exists, check `docs/architecture/*.md` and `docs/adr/*.md` first. Extend an existing ADR rather than re-deciding it, and flag any change that contradicts one.
