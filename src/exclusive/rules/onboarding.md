# Onboarding (Launchpad)
- Root `AGENTS.md` (see the core Role rule) covers naming, routing, and layering conventions. Before proposing or making structural/architectural changes, also check `docs/architecture/*.md` (state management, navigation, data layer, error handling) and `docs/adr/*.md` (numbered ADRs) for the rationale already recorded there.
- Prefer citing or extending an existing ADR over re-deciding or re-explaining something it already settled. If a change contradicts an ADR, flag the conflict instead of silently diverging.
